# inside-out: Personal Moments Manager

## Project Description
Inside Out is an application designed to support the study of proper Java architecture. The project allows users to save moments they want to remember by associating them with a date, emotion, and description.

In addition, a second part, which is still under development, will also allow users to include movies they are watching and the emotions they have generated.

## Prerequisites
To run this project, you need the following installed on your system:

Java Development Kit (JDK): Version 21.
Maven: Version 2.8.1 or higher. The project was created using the maven-archetype-quickstart archetype.
